01

开始前，只确认两件事

✓

能看到 Agent

工作台的 Agent / Skills 列表中可以看到“HTX 火宝 Agent”。

✓

已启用图像生成

公司提供的账号或工作区已具备图像生成能力。

无需个人 API Key只有 Agent 文件、没有图像生成权限时不能出图。若入口缺失或显示“图像生成不可用”，联系工作区管理员。
02

3 步完成一张海报

1

打开火宝 Agent

新建一个任务，并确认当前使用的是 HTX 火宝 Agent。

2

粘贴 3 项文案

副标题、主标题、日期 / 时间一次给齐，文案将逐字保留。

3

下载最终 PNG

等待自动生成、裁切、排版和检查，只下载最终通过版本。

逐字确认

提交前完成文案审核；Agent 不负责润色、补充或删减。

$ 会触发金币

只有字面量“$”触发 1–2 枚美元金币；USDT、U、百分比不会触发。

日期可以留空

写“日期：留空”后不显示日期和时钟图标。

标题最多两行

信息过多时，提交前拆成副标题 + 主标题或主动精简。

05

成品验收清单

  • 文案与提交内容逐字一致，主标题不超过两行。
  • 核心奖励数字、货币符号或百分比为黄色。
  • 右上角官方 Logo 与火宝 T 恤白色火焰标识都在。
  • 火宝的脸、角、双手、关键手势和主题道具完整。
  • 没有乱码、额外 Logo、漂浮小图标、网络节点或发光连接线。
  • 文案含“$”时有 1–2 枚金币且不挡字；不含“$”时没有无关美元金币。
06

常见问题

没有即梦 / OpenAI API，能用吗？

能。前提是公司提供的 Codex / ChatGPT 工作区已经启用内置图像生成。

只使用 Claude，能直接出图吗？

普通 Claude 默认不能生成火宝插画。请先用 Claude 确认 3 行文案，再复制到 Codex 的 HTX 火宝 Agent；除非管理员已为 Claude 接入并适配生图工具。

看不到 HTX 火宝 Agent 怎么办？

Agent 尚未安装、同步或未对该账号开放，请联系工作区管理员。

哪些需求不适合这个 Agent？

VIP 金色、复杂长图、透明素材、模板复刻、信息密集规则图，以及需要品牌母版严格复刻的任务。
