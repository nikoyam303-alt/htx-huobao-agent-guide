05

成品验收清单

  • 文案与提交内容逐字一致，主标题不超过两行。
  • 核心奖励数字、货币符号或百分比为黄色。
  • 右上角官方 Logo 与火宝 T 恤白色火焰标识都在。
  • 火宝的脸、角、双手、关键手势和主题道具完整。
  • 没有乱码、额外 Logo、漂浮小图标、网络节点或发光连接线。
  • 文案含“$”时有 1–2 枚金币且不挡字；不含“$”时没有无关美元金币。
06

常见问题

一定要使用即梦或 OpenAI 吗？

不需要。只要当前环境连接了一个可被 Agent 调用、能接收提示词并返回图片的兼容生图工具即可。

只使用 Claude，能直接出图吗？

可以，但必须先为 Claude 连接至少一个兼容生图工具。未连接任何工具时，Claude 可以整理文案，但火宝 Agent 无法生成图片。

同时连接了多个生图工具怎么办？

用户指定平台时按指定工具调用；未指定时使用当前环境的默认图片生成工具。

看不到 HTX 火宝 Agent 怎么办？

Agent 尚未安装、同步或未对该账号开放，请联系工作区管理员。

哪些需求不适合这个 Agent？

VIP 金色、复杂长图、透明素材、模板复刻、信息密集规则图，以及需要品牌母版严格复刻的任务。
